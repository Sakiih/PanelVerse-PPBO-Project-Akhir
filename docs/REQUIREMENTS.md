# PanelVerse — Requirements

**Status:** Draft — validasi bersama seluruh anggota.

## Functional requirements

| ID | Kebutuhan | Prioritas | Pemilik | Status |
|---|---|---|---|---|
| FR-01 | Pengunjung dapat melihat homepage | High | Member 3 | Planned |
| FR-02 | Pengunjung dapat melihat katalog komik | High | Member 3 | Planned |
| FR-03 | Pengunjung dapat mencari dan memfilter komik | High | Member 3 | Planned |
| FR-04 | Pengunjung dapat melihat detail komik | High | Member 4 | Planned |
| FR-05 | Pengunjung dapat melihat daftar chapter | High | Member 4 | Planned |

| FR-11 | Sistem menyediakan REST API | High | Member 6 | Planned |

## Non-functional requirements

- Konsistensi UI dan responsive layout.
- Validasi input dan otorisasi yang sesuai.
- Struktur kode modular dan maintainable.
- Penerapan PBO dan SOLID yang dapat dibuktikan.
- Tidak menyimpan secret di repository.
- Dokumentasi instalasi dan pengujian tersedia.

## Scope decisions

Catat fitur yang dikeluarkan dari MVP agar anggota tidak mengembangkan fitur di luar kesepakatan.
